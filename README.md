# Personal Portfolio Website

A modern and responsive personal portfolio website built with React, showcasing my projects, skills, and professional experience.

## Features

- 🎨 Modern UI/UX design with smooth animations
- 📱 Fully responsive layout
- 🎯 Multiple sections including About, Skills, Projects, and Contact
- 🌟 Interactive particle background
- 📄 Downloadable resume
- 💻 Technical and personal skills showcase
- 🎨 Lottie animations for enhanced visual appeal

## Technologies Used

- **Frontend Framework:** React.js
- **UI Components:** React Bootstrap, Material-UI
- **Animations:** React Reveal, React Parallax Tilt, Lottie
- **Routing:** React Router DOM
- **Icons:** React Icons, Material Icons
- **Styling:** CSS, Bootstrap

## Getting Started

### Prerequisites

- Node.js (v12 or higher)
- npm or yarn

### Installation

1. Clone the repository
   ```bash
   git clone [your-repo-link]
   cd Personal-Portfolio
   ```

2. Install dependencies
   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server
   ```bash
   npm start
   # or
   yarn start
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser

### Building for Production

```bash
npm run build
# or
yarn build
```
